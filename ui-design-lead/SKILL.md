# 🎨 UI Design Lead: Distinctive Frontend & Visual Design Suite

Use this skill when designing, styling, or auditing web interfaces, components, and applications to ensure bold, bespoke, and anti-cliché visual design.

---

## 🏛️ Core Design Philosophy

A great user interface has a clear point of view. It rejects generic AI boilerplate (identical card kits, neon gradients, and noisy scroll animations) in favor of domain-grounded aesthetics.

For specifications and audit rules:
- [Design Tokens & Spacing Systems](./references/design_tokens.md)
- [Anti-Cliché Design Tropes Checklist](./references/anti_cliche_checklist.md)

---

## 🔄 The 4-Stage Visual Design Workflow

### Stage 1: Domain Grounding & Personality
Identify the subject's world:
- Industrial/Technical $\rightarrow$ High-density data grids, crisp hairlines, mono-spaced metrics.
- Editorial/Creative $\rightarrow$ Expressive typography, generous whitespace, warm canvas tones.

### Stage 2: Token Architecture (4–6 Tokens)
Define a tight, semantic color system before writing CSS:
- Canvas & Surface tones (never pitch-black `#000` or sterile white `#fff`).
- High-contrast text tokens.
- Exactly **one** memorable focal accent color.

### Stage 3: Wireframe & Typographic Rhythm
- Set strict line-length caps (`max-width: 65ch`–`75ch`) on text.
- Use whitespace and structural dividers instead of boxing every element into a card.
- Build responsive layouts down to mobile viewports.

### Stage 4: Restraint & Self-Critique
Before finalizing, audit against the [Anti-Cliché Checklist](./references/anti_cliche_checklist.md):
- Cut unnecessary decorations.
- Ensure animations only answer direct user interactions (expands, clicks, transitions).
- Verify accessible contrast ratios (WCAG AA compliant).
